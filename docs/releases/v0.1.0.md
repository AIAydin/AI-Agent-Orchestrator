Forgeboard v0.1.0 is an unsigned development prerelease of the local-first desktop workshop.

Implemented solo setup is fully UI-driven: install the app, choose safe defaults or use the setup
wizard, and open the deterministic demo without Node.js, pnpm, an account, an API key, or edits to
source/configuration files. The release includes the spatial canvas, local agent execution,
application-managed worktrees, loopback previews, and authoritative primary-checkout Git review,
staging, and commits. Broader unchecked product areas remain under active construction in
[`IMPLEMENTATION_CHECKLIST.md`](https://github.com/AIAydin/AI-Agent-Orchestrator/blob/v0.1.0/IMPLEMENTATION_CHECKLIST.md).

## Choose an artifact

- macOS Apple Silicon: the `arm64.dmg` artifact.
- macOS Intel: the `x64.dmg` artifact.
- Windows x64: `Forgeboard Setup 0.1.0.exe`.
- Linux x64: the AppImage for a portable launch, or the DEB for a system installation.

Each platform also has a `SHA256SUMS` file. The release attaches immutable corresponding-source
archives for the bundled Git toolchain.

## Signing status

The macOS and Windows binaries in v0.1.0 are intentionally unsigned because repository signing
credentials are not configured. macOS Gatekeeper and Windows SmartScreen may therefore display
their normal provenance warnings. Do not disable operating-system security globally; verify the
checksum and source, then use the operating system's per-app approval only if you trust this build.
